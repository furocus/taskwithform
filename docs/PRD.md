# PRD

## Overview

複数教科の未完了課題を、一覧と簡易カレンダーで把握するローカルファーストの課題管理アプリ。

課題の原本は将来的にGoogle Classroom APIから取得する。ユーザー固有の進捗はサーバーへ保存せず、端末内のIndexedDBへ保存する。

## Goals

- 提出期限の見落としを減らす
- 教科ごとの課題量を視覚的に把握できる
- 次に処理すべき課題を判断しやすくする
- 完了した課題を通常画面から取り除き、未完了課題へ集中できるようにする
- サーバーに課題・進捗・Googleトークンを保存しない
- PCとスマートフォンで利用できる画面設計にする

## Non-Goals

- 課題の途中経過や進捗率管理
- Kanbanによる複数ステータス管理
- 複雑なサブタスク管理
- 複数ユーザー間の共同編集
- 端末間のリアルタイム同期
- TaskDepotの非公開APIやCookieの利用
- MVP段階でのGmail・Google Calendar連携

## User Stories

- ユーザーは直近の課題を期限順に確認できる
- ユーザーは課題を教科色で識別できる
- ユーザーは課題を完了にできる
- 完了した課題は未完了一覧から自動的に消える
- ユーザーは誤操作直後に完了を取り消せる
- ユーザーは今後7日間の課題量を確認できる
- ユーザーは課題の詳細と元ページへのリンクを確認できる
- ユーザーは再読み込み後も自分の進捗を維持できる

## Core Screens

### PC

- 未完了課題の一覧を主画面として表示
- 下部に7日間の簡易タイムライン
- 課題詳細はモーダルまたはサイドシート

### Smartphone

- 課題一覧を主画面として表示
- ステータスはタブで切り替える
- カレンダーは横スクロールまたは別タブ
- 課題詳細はボトムシート

## Completion Model

- 未完了: 完了記録が存在しない
- 完了: 課題IDに対応する完了記録が存在する

完了操作後は課題を通常の一覧と期限表示から除外する。誤操作対策として、操作直後に短時間の「元に戻す」を表示する。

細かな進捗率、途中状態、チェックリストはMVPでは扱わない。

## Subject Colors

- 数学: Blue
- 英語: Purple
- 国語: Red
- 理科: Green
- 社会: Orange
- 情報: Cyan
- その他: Gray

色だけに依存せず、教科名も必ず表示する。

## Local Data

MVPで端末内に保存する情報:

- 課題ID
- 完了フラグ
- 更新日時
- 完了日時
- 最小限の表示設定

保存しない情報:

- Googleパスワード
- GoogleログインCookie
- Access Token
- Refresh Token
- Gmail本文
- TaskDepotセッション
